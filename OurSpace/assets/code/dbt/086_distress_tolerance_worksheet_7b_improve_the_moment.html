IMPROVE the Moment

For each IMPROVE skill, write down what you did during the week, and write down a number to indicate how effective the skill was in helping you tolerate the distress and cope with the situation (keeping you from doing something to make the situation worse). Use the following scale:

I could use skills, tolerated distress, and resisted problem urges. 1 2 3 4 5

I was able to cope somewhat, at least for a little while. It helped somewhat.
