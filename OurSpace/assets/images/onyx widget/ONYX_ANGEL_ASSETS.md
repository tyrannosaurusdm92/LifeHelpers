# Onyx angel accents: asset credits

These are pre-existing open-license SVG assets. No halo or wing shapes were drawn or procedurally generated for this project.

## Halo

- Local file: `onyx-angel-halo.svg`, copied unchanged from [Icon Monks](https://github.com/designmonks-llc/icon-monks/blob/main/svg/regular/halo.svg).
- License: MIT. Copyright (c) 2026 Design Monks.
- Presentation: CSS uses the existing halo icon as a mask and clips away the source icon's other artwork, leaving its halo ring. The source SVG paths are unchanged.

## Wing

- Local file: `onyx-angel-wing.svg`, copied unchanged from [Twemoji](https://github.com/jdecked/twemoji/blob/main/assets/svg/1fabd.svg).
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as documented by the [Twemoji project](https://github.com/jdecked/twemoji#attribution-requirements).
- Attribution: Twemoji contributors.
- Adaptation: CSS mirrors one instance of the source wing to form a left/right pair. The source SVG path is unchanged.
