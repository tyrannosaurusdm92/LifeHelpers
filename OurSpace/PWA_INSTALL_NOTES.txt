To connect to frontend later:
  - Change legacy script/foo.js paths to script/js/foo.js.
  - Change WASM paths to script/wasm/foo.wasm.
  - Add <link rel="manifest" href="/PATH_TO_SITE/ourspace.webmanifest"> to each host page.
  - Load the existing OurSpaceAuth script BEFORE script/js/ourspace-pwa-client.js.
  - In authenticated pages call OurSpacePWA.subscribe() only from a user click/tap.
  - The client automatically registers service-worker.js (when included).
  - Use settings.alerts.* backend actions from the Settings menu.
  - Choose a free Web Push transport: Firebase Cloud Messaging with public web config
    and public VAPID key, or a VAPID Web Push gateway. The backend private service
    account belongs ONLY in Apps Script script properties, never this repository.
  - Current backend dry run reports Firebase and Web Push gateway not configured.
  - On iPhone/iPad, install as Home Screen web app; request notification permission
    inside the installed app on user tap (iOS/iPadOS 16.4+).
  - Use transparent top notification window variants only for in-app/tab visuals and
    notification images. Installed OS launcher artwork is static; its badge supports
    an unread count or dot, not two-digit code rotation.
  - App icons leave the website's central OurSpace logo untouched.
  - No SMS, no Eqivo, no paid phone network required.

Consolidation policy: top-level script/*.js took priority over copies at script/js/*.js
when the same name differed, because the archive included more recent no-sound and
widget updates in top-level files. Original nested PrismShift ESM modules were
renamed to prismshift-core-*.js / prismshift-adapters-*.js and relative imports
rewritten to sibling paths. No game, Onyx, or messenger logic was otherwise edited.

A browser's own UI may refuse to show a launcher badge, alpha icon window, or
notification depending on platform settings. OS and browser control those surfaces.
