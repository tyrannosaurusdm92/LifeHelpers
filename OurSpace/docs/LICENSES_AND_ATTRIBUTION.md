## 1. SOURCES-LICENSES.md

# Source / reference notes

## Supplied Universal Visual Builder

Used as the layout-system reference for nested parent/child containment, explicit hierarchical grouping, modular shells, responsive panels, and independent nested content surfaces. No builder source file is redistributed in this package.

## Supplied Discord-clone archive

All eight nested archives were inspected. The resulting Work UI is original vanilla HTML/CSS/JS and does not copy their framework/backend implementations.

Patterns intentionally carried over at the design/architecture level:

- server-style primary rail
- server-scoped channel list
- active server/channel affordances
- chat viewport + bottom composer
- channel-specific message continuity
- responsive sidebar/drawer behavior
- auto-growing message input and Enter/Shift+Enter behavior

Explicit MIT license files were present at the root of these supplied copies:

- `discord-clone-main (3)` — MIT, copyright Issam Seghir (2023)
- `discord-clone-main (6)` — MIT, copyright Maheshnath09 (2024)
- `discord-clone-main (8)` — MIT, copyright Aarav Mishra (2023)
- `discord-clone-master (1)` — MIT, copyright Nirmalya Nayak (2026)

Other supplied copies without a root license were treated as visual/architectural study references only; their source code was not copied into Work.

## LifeHelpers / Onyx GitHub tree

The package is designed to live under `LifeHelpers/OurSpace/` and use the existing `LifeHelpers/Onyx/js/ai-brain-config.js` plus the already deployed OurSpace Apps Script endpoint. No Onyx brain files are copied into this ZIP.

## 2. SOURCES.md

# Design sources

User-provided materials:
- `OurSpace_Detailed_Functional_Description(2).txt`: page names, private/public access boundaries, portal recovery behavior, and two-profile structure.
- `OurSpace_Standalone_Design_Widget(2).html`: base design editor adapted into an embeddable page-level widget, preserving drag/close, color wheels, hex code, images, presets, custom targets and export.
- `Whimsical OurSpace Moonlit Cottage Emblem(3).png`: login logo and PWA icon source.
- `myspace-clones.zip`: visual/structural inspiration; especially `toms-myspace-page-master/css/styles.css`, `toms-myspace-page-master/index.html`, and `anyspace-main/core/components/section_music.php` / comment layouts. Server, PHP, mobile Java/Android and dependency manifests were not copied.
- The newly attached cottage emblem is the design widget bubble icon.

Online visual references: MySpace layout generator's Background/Sections/Headings/Main Text styling UI and MySpace/SpaceHey-style heading, link, background and module-specific targeting. The site design uses custom code and its own scoped design registry rather than injecting remote pasted layout code into editable profile fields.
