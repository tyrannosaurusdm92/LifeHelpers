## Architecture

```text
assets/code/index.html + generator.css (workshop only)
      -> generator-app.js
      -> onyx-responses.js (widget-facing API; generation, chat, export)
          -> lexical-retrieval.js + lexical-score.wasm (references)
          -> conversation-engine.js -> context-memory.js (private facts and turns)
          -> quality-guard.js (warnings and optional model rewrite)
          -> backend-client.js -> local relay /api/onyx-chat
                -> EXISTING Apps Script /exec (onyx.chat)
                     -> existing AI Brain -> Gemini IF configured on backend
```

The C source `similarity.c` is compiled into portable WebAssembly as an additional primitive for future ranking experiments. `lexical-score.wasm` remains the currently invoked scorer, preserving behavior.

## Browser execution

Run `npm start` from the project root, then open http://127.0.0.1:8765/. This is a Node.js dev relay and static server, not a Python service. The existing Apps Script URL is locked in `backend-client.js` / `script/dev-server.mjs`.

A public GitHub Pages deployment CANNOT use the bundled Node relay, and direct browser calls to Apps Script may fail on redirect/CORS. Deploy a trusted same-origin bridge or integrate with the authenticated OurSpace host. Never embed a Gemini API key or session token into static files, query parameters or JSONP.

## Memory semantics

* Every turn is available as short-term continuity for the current running page (up to 10) even without saving.
* Ticking “Save conversation turns on this device” adds an IndexedDB copy scoped to profile / mode / thread; a thread is capped at 40 saved turns.
* Explicit “Remember note” is the only way to create persistent factual notes. Up to 250 per profile/mode are retained. Notes are ranked for relevance to the next question.
* No server-side long-term memory, no fine-tuning, no cross-device sync and no access to personal health/therapy records is claimed.
* Browser-local storage is not security-grade encryption. Anyone with access to that browser profile may read stored notes.
* Never use a generated example as proof that a user actually said or did something. Memory is not built by pretending source examples are events.

## Privacy & safety

The workshop is restricted to nonclinical Work/Leisure. Professor and medical support must use separate properly authorized paths. The package does not add game art, widget visuals, Happy Home or Adventures assets, additional chat tabs, or any tenth mood. It contains no Python runtime or Python source.

## Scale and compressed-size disclosure

User-requested target: **10,000–30,000 KB of additional code after compression**. This is a size target, not an outcome demonstrated by the ZIP. Pass 2 adds focused, tested modules and does **not** pad the archive with repetitive autogenerated text, unrelated third-party repositories, inert files, or fake model weights to reach the target. See `BUILD_METRICS.json` for exact file and compressed-byte counts after packaging. Adding true generative capability requires a trained model and an inference runtime or a working authenticated backend; arbitrary bytes do not increase Onyx’s intelligence.
