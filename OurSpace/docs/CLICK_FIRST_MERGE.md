# Click-First Merge Notes

Reference interaction: the supplied standalone `perspective_surface_scanner.html` selected polygons by clicking directly on the canvas and separated selection from move/vertex editing.

This package applies that behavior to the locked living-room build while retaining:

- fixed latest-layout scene objects
- interactive SVG iframes
- interactive AC switch
- click-to-fill picture frames
- reduced fish population/speed
- background-only scanning
- shift multi-selection
- named GeoJSON groups
- ungroup-to-independent-groups behavior
- high-resolution edge/color scanner and overlap repair
