# Happy Home in Onyx

The Happy Home room is embedded in the Virtual fullscreen tab in `onyx.html`; it is not a second standalone page. The merged room keeps its editor, store, inventory, room art, weather openings, and Onyx spatial integration.

Room and store code is under `js/onyx/games/virtual/` and `css/onyx/games/virtual/`; room data is under `json/happy-home-`. Images are grouped under `https://raw.githubusercontent.com/tyrannosaurusdm92/LifeHelpers/main/OurSpace/assets/images/games/virtual/{room,store,inventory,atlases}/`, with room audio and weather videos under `https://raw.githubusercontent.com/tyrannosaurusdm92/LifeHelpers/main/OurSpace/assets/audio/games/virtual` and `https://raw.githubusercontent.com/tyrannosaurusdm92/LifeHelpers/main/OurSpace/assets/video/games/virtual/room`.

The legacy Happy Home `#admin` shell is excluded. Onyx's own module chat test mode is separate.
