# Happy Home · Virtual / Health Finished Living Room

Entry point: `virtual_health.html`

This build embeds the finished Happy Home living room into the supplied Virtual / Health shell.

The shell's 🟢 decorating button opens a movable/resizable Happy Home design panel. The shell's ✖️ decorating button closes it. The panel can collapse into a 50×50 green bubble.

Tabs:
- **Inventory Placement** — intentionally blank placeholder for future placement of already-owned store purchases.
- **Room Customization** — designs the immutable authored GeoJSON architecture. No geometry/scanner editing is exposed.
- **Furniture Customization** — designs only authored SVG color/pattern regions with large external color controls.

Furniture channel naming is normalized to Main Color / Accent 1 / Accent 2 / Accent 3 when applicable. Light-emission colors are named Light Bulb 1 / Light Bulb 2.

Weather/outdoor playback, picture-frame uploaders, AC interaction, fan/lamp interaction, fish, and other scene behavior remain in the room iframe.
