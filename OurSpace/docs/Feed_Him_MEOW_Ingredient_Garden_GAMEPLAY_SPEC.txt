PAGE ORDER / CORE FLOW
----------------------
Page 1: Level Select
Page 2: Recipe Generator
Page 3: Fishing
Page 4: Ingredient Garden
Page 5: Kitchen

The level is selected first, then the recipe is generated. The generated recipe is authoritative for both Fishing and Ingredient Garden.

ROUTING RULES
-------------
1. Player selects an available level on Page 1.
2. Page 1 opens Page 2 and stores the selected account level/run seed.
3. Page 2 generates exactly one active recipe for that run.
4. Inspect recipe. Ingredients for fish-type ingredients.
   Initial fish IDs: salmon, shrimp. Keep the fish-ID list data-driven for future fish additions.
5. If the recipe contains NO fish:
   - Continue bypasses Page 3 entirely.
   - Go directly from Page 2 to Page 4 Ingredient Garden.
6. If the recipe DOES contain fish:
   - Continue goes from Page 2 to Page 3 Fishing.
   - Fishing receives the recipe's fish requirements.
   - Fishing may be completed well, partially, or poorly; it must never hard-lock the run.
   - On Fishing continue, go to Page 4.
7. Page 4 receives:
   - selected level;
   - recipe ID and full ingredient set;
   - fish inventory earned in Fishing;
   - Fishing performance result;
   - solo/duo state;
   - account progression and best-score data.
8. Completing Ingredient Garden unlocks/continues to Page 5 Kitchen.

FISH INVENTORY → GARDEN HANDOFF
-------------------------------
Fishing catches are carried into Ingredient Garden as ingredient inventory.

For each required fish ingredient:
    gardenFishOutstanding = max(0, gardenFishQuota - fishInventoryCount)

Examples:
- Garden quota wants 6 Salmon tokens and Fishing inventory contains 6 Salmon: Salmon Garden target becomes 0.
- Garden quota wants 6 Salmon and Fishing inventory contains 4 Salmon: Garden needs only 2 Salmon.
- Fishing inventory exceeds the Garden quota: Garden target is 0; surplus can remain in run inventory but does not create a negative target.

“Did badly at Fishing” rule:
- A bad/partial Fishing result NEVER blocks Ingredient Garden.
- If any required fish remains short after Fishing OR Fishing explicitly reports its low/fail performance state, apply exactly one +5% difficulty modifier to the Garden level.
- Apply the +5% once to the level generator’s overall difficulty scalar: effectiveDifficulty = baseDifficulty × 1.05.
- Do NOT separately add 5% to moves, targets, blockers, and timers, because that compounds into more than a 5% difficulty increase.
- The generator uses effectiveDifficulty to choose slightly tighter targets/moves/time/blocker pressure.

RECIPE → GARDEN OBJECTIVE MODEL
-------------------------------
Ingredient Garden collects the ingredients required by the active recipe, not arbitrary unrelated ingredients.

The culinary amount string (for example “1 cup”) is display information. The puzzle should use a separate integer gardenUnits quota for each ingredient so the board never has to interpret cups, tablespoons, ounces, etc. If gardenUnits is absent, generate it deterministically from level number + recipe ingredient count + difficulty seed.

Garden objective list = every recipe.ingredients entry with gardenUnits > 0, minus any carried Fishing inventory for fish ingredients.
Recipe seasonings are NOT automatically board objectives unless they are also represented as normal recipe.ingredients with image assets.

The Garden can add non-objective filler ingredients to make a playable board, but filler must come only from the supplied ingredient asset catalogue. It must never introduce an ingredient as a required objective unless the recipe calls for it.

UNLIMITED LEVEL SYSTEM
----------------------
Ingredient Garden has no final level. Levels are generated continuously.
- Account progress is authoritative.
- Default to level 1 only when account progress does not exist.
- Page 1 shows 45 numbered paw nodes at one time.
- After the player progresses beyond a visible 45-level batch, generate/show the next 45-node batch using the same 45-node path geometry with new absolute level numbers.
- Previous 45-level batches remain navigable for replay.
- Completed levels retain best score, stars, best currency result, best combo/chain, and mode.
- Future levels are locked until account progression reaches them.
- Replaying an old level never lowers account progress.

PAGE 4 — INGREDIENT GARDEN, 1050×850
-------------------------------------
The Garden game is a fixed 1050×850 canvas.

Recommended landscape layout:
- Top HUD: 1050×90.
- Left objective/score rail: x=10..180, y=105..760.
- Main board: approximately x=195..855, y=105..765 (square play region; default 8×8 grid).

The exact art can overlap those conceptual regions, but the board must remain fully visible and tappable at 1050×850.

TWO GAMEPLAY FAMILIES
---------------------
Every generated Garden level chooses one primary interaction family. The choice is saved with the level seed so replaying the same level uses the same mode.

A. TRACE / CONNECT MODE — PUDDING-POP-LIKE
- Touch/click one ingredient and drag a continuous line through matching ingredient tokens.
- Every next token must be within one board cell of the previous token.
- Orthogonal AND diagonal neighbors are legal: row delta <=1 and column delta <=1, excluding the same cell.
- A token cannot be used twice in the same trace.
- Default minimum valid chain: 3 matching ingredient tokens.
- Releasing a valid chain clears/collects it, refills the board, then resolves any secondary cascades.
- Releasing an invalid chain (<3 or broken) cancels without consuming the player’s turn/move.
- The active trace line/head are CODE-RENDERED with the Aurora/WASM effect engine. No bursteffects image sprite is required. The ribbon responds to ingredient identity, trace velocity, charge/field drift, and reduced-motion settings.
- Longer chains increase score and can create special effects/free-booster chances.

Recommended trace thresholds, stored in JSON so they can be rebalanced:
- 3–4: normal clear.
- 5–7: create one line/row/column special.
- 8–11: stronger area/ingredient special.
- 12+: premium chain event; guaranteed special and eligible for “particularly well” free-booster reward.

B. SWAP / MATCH-3 MODE — CANDY-CRUSH-LIKE
- Swap exactly two orthogonally adjacent board ingredients.
- A normal swap is legal only if it creates at least one horizontal/vertical match of 3+ OR activates a legal special/booster interaction.
- Invalid swaps animate back and do not consume a move/turn.
- Matches clear, recipe targets increment, gravity refills, and automatic cascades resolve before the next player may act.
- Match 4 in a straight line: line-clear special.
- Match 5 in a straight line: ingredient-color clear special.
- T/L match: local area-clear special.
- Specials are Feed Him MEOW/Garden themed; do not import Candy Crush candy art.

MODE DISTRIBUTION
-----------------
The generator must support both families indefinitely. Default balance may begin at 50% Trace / 50% Swap, seeded by the level number so a level’s mode is stable on replay. The percentage must be data-driven, not hard-coded into UI code.

BOARD GENERATION
----------------
Default board: 8×8.
- Never generate an immediately dead board.
- Swap levels should not begin with unintended automatic matches unless the level template explicitly calls for them.
- Trace levels must begin with at least one legal 3+ chain.
- Recipe-required ingredients receive enough spawn weight that the goal is achievable.
- Filler ingredients create variety but cannot make the recipe goal mathematically impossible.
- If no legal action remains, auto-shuffle eligible ingredients without charging a move/turn.
- Generated blockers may be introduced gradually, but they must never make a required ingredient unreachable without a defined solution.

PASS 18 SEEDED BOARD TOPOLOGY / ECOLOGY
----------------------------------------
The 8×8 coordinate space is now a maximum envelope, not a requirement that all 64 cells be playable. The seeded randomizer may mask inactive holes to create classic, diamond, split-garden, ring-bed, terrace, flower-cross, or twin-island beds. Inactive cells never match, trace, accept blockers, or receive gravity/refill.

Each generated level also receives a seeded level program: calm beds, petal release, vine watch, thorn maze, cascade orchard, relay greenhouse, or mixed ecology. The program biases topology, hazards, starting specials, and linked-board behavior while retaining deterministic replay.

Eligible levels may include a smaller linked relay garden (4×4, 4×5, or 5×5). Main-board cascades charge it. Clearing a 3+ connected ingredient cluster on the relay maps that ingredient back to the main garden to trigger a free mapped clear/cascade. If the ingredient is unavailable on the main board, relay energy attacks flower petals, vines, or thorns instead. Relay actions do not consume the normal Garden move.

HAZARD ECOLOGY
----------------
- VINES: occupy/lock an ingredient. On their scheduled creep turn they can spread to one adjacent eligible cell. Damaging a vine suppresses that creep cycle. New spread is rejected if it would leave the board unsolvable.
- FLOWER PLOTS: cover a real ingredient with 2–4 petal layers. Adjacent clears/eligible specials strip petals. The protected ingredient cannot move or be collected until the final petal layer is removed.
- THORNS: layered ingredient locks requiring repeated adjacent/special pressure.
- INFECTION: retained only as a rare late-game legacy spreading hazard, also solvability checked.

Hazards must favor non-objective filler when spreading and must never intentionally eliminate the only route to a required ingredient.

LEVEL DIFFICULTY INPUTS
-----------------------
Base difficulty may scale using:
- account level;
- number of recipe ingredients;
- total gardenUnits target;
- active board ingredient variety;
- blocker count/layers;
- move budget or timer budget;
- special-piece opportunities;
- Fishing +5% modifier when applicable.

Use one normalized difficulty score and derive parameters from it. Do not compound independent +5% penalties.

MOVES / TIME
------------
Most levels should use a move budget because both researched puzzle families are strongly compatible with turn efficiency. Timed levels may also be generated so the user’s “add more time” boosters have a direct role.
- Move-limited level: HUD shows moves remaining.
- Timed level: HUD shows time remaining.
- Mixed constraint levels are optional and should be introduced only at higher difficulty.
- Accessibility option should be able to exclude timed levels from generation without blocking progression.

SOLO PLAY
---------
One player owns every board action. Score, objective progress, boosters, and result all apply to that player’s account/run.

DUO PLAY
--------
Duo uses one shared board and one shared recipe objective.
- Jasper ALWAYS takes the first turn.
- William ALWAYS takes the second turn.
- Then alternate Jasper → William → Jasper → William until the round ends.
- The inactive player’s board interaction layer is disabled: no selecting, dragging, swapping, or board-target booster use.
- In Swap mode, a turn is one valid swap plus its full cascade resolution.
- In Trace mode, a turn is one valid completed trace plus its full refill/cascade resolution.
- Invalid swap/invalid trace does NOT hand over the turn.
- While cascades/animations resolve, both users are temporarily locked out.
- After resolution, enable only the next player.
- The HUD must visibly say “Jasper’s turn” or “William’s turn.”
- A board-changing booster counts as that player’s turn if it replaces the main board action. Pure meta boosters such as adding time/moves do not by themselves end the turn.
- Score/objective progress is shared for the level. Keep per-player contribution stats for the result screen if desired, but never make contribution determine whose turn is next.

SCORING / STARS / REPLAY
------------------------
Completion is objective-based; score measures quality.
Recommended scoring components:
- points per ingredient cleared;
- larger bonus for recipe-target ingredients;
- chain/match-length bonus;
- cascade/combo multiplier;
- special activation bonus;
- remaining moves/time completion bonus;
- no penalty for using carried Fishing inventory.

Each generated level stores three score thresholds for 1/2/3 stars.
- Meeting the recipe objective completes the level and gives at least 1 star.
- 2/3 stars require stronger score performance.
- Best score and best star result persist to the account.
- Any completed level, including a low-score 1-star clear, can be replayed indefinitely.
- A replay may improve best score/stars and can award additional currency.
- Replays can also award free boosters when performance qualifies.
- Never force a player to accept a low score as final.

“PARTICULARLY WELL” FREE BOOSTER RULE
-------------------------------------
A level is eligible to grant a free booster when at least one of these data-driven performance conditions is met:
- three-star result;
- exceptional trace chain (default threshold 12+);
- large cascade/combo threshold;
- substantial moves/time remaining;
- new personal best above the level’s high-performance threshold.

The exact booster chosen may be deterministic or weighted random, but show the award before returning to Level Select/Kitchen.

CURRENCY SYSTEM — EXACT REQUIRED FORMAT
---------------------------------------
🟤 = copper
⚪ = silver
🪙 = gold
🔘 = platinum

Display order everywhere:
🟤0 ⚪0 🪙0 🔘0

Caps and conversion:
- copper: 0–9
- silver: 0–9
- gold: 0–9
- platinum: unlimited
- 10 copper = 1 silver
- 10 silver = 1 gold
- 10 gold = 1 platinum

Normalize from low to high after EVERY earn/spend transaction:
while copper >= 10: copper -= 10; silver += 1
while silver >= 10: silver -= 10; gold += 1
while gold >= 10: gold -= 10; platinum += 1

This automatically enforces the 9 cap on copper/silver/gold while allowing platinum to grow without limit.
Never display an old generic coin/gold-bar currency in Ingredient Garden.

EARNING CURRENCY
----------------
Currency is earned from Garden play, not only from first-time clears.
Reward calculation can use:
- base level completion reward;
- score/star bonus;
- combo/chain bonus;
- first-clear bonus;
- replay improvement bonus;
- perfect/near-perfect performance bonus.

Low-score levels may be replayed specifically to earn a better score, free boosters, and more currency. Currency payout values must be data-driven in JSON so they can be balanced without editing board logic.

SPENDING CURRENCY / BOOSTERS
----------------------------
Currency can buy in-level boosters. Prices belong in JSON and must use the four-currency wallet.
Required supported effects include:
- add time on timed levels;
- add moves on move-limited levels;
- remove a selected board ingredient/piece;
- reduce an outstanding ingredient requirement (“take away ingredients” from the goal);
- swap any two eligible ingredients so a better match/trace setup can be made;
- shuffle the board;
- inject/spawn more currently required recipe ingredients;
- collect/remove all visible copies of a selected ingredient type;
- optional reward multiplier/mystery booster.

The nine board_ui_booster_N slots are presentation slots, not hard-coded logic. Booster ID/effect/cost/unlock level must come from data. Locked variants show until the booster’s unlock condition is met.

RECOMMENDED BOOSTER SLOT SEMANTICS
----------------------------------
1. Scent Sweep — select an ingredient type; collect/remove all visible copies.
2. Recipe Trim — reduce one outstanding recipe ingredient quota by a configured amount.
3. Paw Hammer — remove one selected piece/blocker.
4. Retry Heart / Safety — one configured continue/near-miss assist; do not create a general life system unless desired.
5. Time/Move Paw — +time on timed levels or +moves on move-limited levels.
6. Mystery Gift — grants one random eligible booster.
7. Reward Charm — boosts currency/score reward for this run.
8. Ingredient Crate — injects required recipe ingredients into legal cells.
9. Imperial Swap — swap any two eligible ingredients without requiring the swap itself to form a match.

Keep existing Onyx floating booster behavior compatible. If Onyx boosters and the board booster rail share an effect, they must call the same underlying effect handler rather than duplicate logic.

FAILURE / NEAR-MISS
-------------------
A Garden level fails only when its active limit expires (moves or time) before all outstanding recipe ingredients are collected, or a special generated rule explicitly says so.
- Show exactly what remains.
- Allow Retry.
- Allow eligible purchased/free extra time/moves/goal reduction.
- Do not erase the player’s prior best score on failure.
- A Fishing low result is not a Garden failure; it only adds the one +5% difficulty modifier described above.

WIN / CONTINUE
--------------
When every recipe ingredient quota is satisfied:
1. Lock board input.
2. Resolve any current cascade/trace animation.
3. Play completion audio.
4. Calculate score, stars, currency, and free booster awards.
5. Save best score/stars/rewards/account progress.
6. Offer Replay for a better score OR Continue to Page 5 Kitchen.
7. Continuing sends the active recipe and collected inventory/state to Kitchen.

ACCESSIBILITY / INPUT
---------------------
- Mouse and touch must both work.
- Trace mode must not require pixel-perfect paths; use cell hit areas and interpolate across adjacent entered cells.
- Keyboard/gamepad assist can select cells and confirm swaps/traces.
- Reduced motion disables/reduces pulsing, fireworks, lightning, and long particle chains but never removes gameplay information.
- Timed-level exclusion is permitted as an accessibility generation preference.
- Active/inactive duo turn state must be conveyed by text, not color alone.
- Do not use pink as a required gameplay color.

PALETTE
-------
Use the established Feed Him MEOW palette: black, white, persimmon orange, cadmium yellow, true #00FFFF cyan, dodger blue, lime green, gold, teal, and turquoise. User-provided logos/ingredient art retain their own intended color.

--- MATCH / TRACE / BLOCKER EFFECTS — CURRENT CODE-RENDERED RULE ---

- vine creep/cutting;

APPENDIX D — CANDYCRUSH.HTML PLACEMENT RULES ADAPTED FOR INGREDIENT GARDEN
===============================================================================
Observed structural ideas from the reference HTML that are useful here:
- World map uses tiled background segments and level buttons tied to map coordinates.
- Map buttons distinguish completed, available/uncompleted, and locked states, and star art is overlaid separately.
- Landscape in-level UI uses a top status area plus a side/bottom booster panel rather than putting controls over the center of the board.
- Pause and booster controls live outside the primary match grid.
- Score/progress and goal information are HUD elements, not board pieces.

Ingredient Garden adaptation:
- Keep the 8×8 board visually central and unobstructed.
- Keep recipe goals/score in the left HUD rail.
- Keep booster inventory/shop on the right/bottom HUD rail.
- Keep move/time and duo active-turn label in the top HUD.
- Keep currency in a compact top strip using 🟤 ⚪ 🪙 🔘 assets/ordering.
- Use paw nodes instead of candy-map nodes.
- Use ingredient artwork instead of candy artwork.
- Use Feed Him MEOW palette and user/open-source replacements only.
