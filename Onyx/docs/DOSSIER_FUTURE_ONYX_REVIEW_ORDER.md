# Future Onyx Review Order — Documentation Only

This is the recommended **future** sequence for getting Onyx close to the dossier target before room construction. Nothing in this checklist is implemented by this documentation pass.

## Gate 0 — Freeze the current technical baseline

Before future edits:

- Keep the real-world global scale fixed unless a hard measurement disproves it.
- Keep an untouched copy of the current FBX and current Cat Only viewer.
- Capture standardized comparison views: front, left/right profile, both front 3/4, both rear 3/4, rear, top/high angle.
- Compare those views against real Onyx references and the dossier visual spec.
- Treat the dossier pose contact sheet as attitude/staging support, not a weight-loss instruction.

## Gate 1 — Body silhouette only

Do not touch face/material/whiskers while evaluating this gate.

Approve:

- shoulder width,
- chest width/depth,
- torso length,
- mid-body substance,
- hip relationship,
- leg length,
- paw size,
- tail base/length/taper,
- static primordial-pouch silhouette.

Success condition: he reads as **large, long, stocky-shouldered and sleek-coated**, not skinny, fluffy, barrel-shaped, or kitten-proportioned.

## Gate 2 — Face anatomy only

After body approval:

- eye depth/position and eyelid relationship,
- forehead/cheek shape,
- muzzle/whisker pads,
- nose bridge/tip/nostrils,
- mouth planes,
- chin/lower muzzle.

Success condition: the face reads as a real black cat from front, profile, and 3/4 without procedural pieces visibly floating above the mesh.

## Gate 3 — Coat/material

After shape approval:

- true-black base read,
- controlled charcoal highlight behavior,
- subtle senior speckling,
- corrected normal/roughness detail,
- chest/belly grizzle without gray-cat drift,
- nose/inner-ear/paw-pad localization,
- green-gold eye readability.

Success condition: **black first, detail second** under all approved test lighting.

## Gate 4 — Whiskers and small anatomy

- natural root locations,
- taper,
- individual curvature,
- mostly white with a little silver/smoky variation,
- asymmetry,
- eyebrow whiskers where appropriate,
- paw-pad/toe/claw detail.

## Gate 5 — Weight and secondary motion

Only after the static body is approved:

- heavy-but-agile acceleration/deceleration,
- shoulder/scapular readability,
- landing/settling mass,
- pouch compress/swing/lag/bounce/settle,
- tail follow-through,
- natural posture shifts.

Avoid whole-torso jelly motion. The pouch should have softer secondary behavior than the ribcage.

## Gate 6 — Broader animation library

Build toward dossier families while preserving natural quadruped anatomy. Professor remains the sole controlled upright exception.

## Gate 7 — Final ordinary-play 2.5D camera

Only after Onyx reads correctly from inspection angles:

- move ordinary play to dossier-approved limited camera presets,
- use orthographic or restrained low-FOV perspective,
- preserve stable scale and limited parallax,
- retain free 360 orbit only in explicit developer/inspection mode if desired.

## Gate 8 — Room work begins

Room construction comes **after** Onyx has passed the earlier visual/motion gates. Later room work should use the dossier's approximate 14 × 16 ft canonical scale, actual Onyx dimensions, furniture-fit checks, and wheelchair-aware routing.
