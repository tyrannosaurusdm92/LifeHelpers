# Five comparative language histories
Profiles: [Spanish](spanish.md), [Fijian](fijian.md), [Mandarin](mandarin.md), [Yoruba](yoruba.md), [Hebrew](hebrew.md). Machine-readable UTF-8 ESM modules are under Onyx/js/language-history and indexed by Onyx/js/knowledge-index.js.

| Choice | Historical root/stage meeting 2,500–3,500-year condition | Sibling branches | Dating caution |
|---|---|---|---|
| Spanish | Latin attested 7th–6th c. BCE | Portuguese, Galician, Catalan, French, Italian, Romanian | Spanish is much later; Catalan classification varies |
| Fijian | Proto-Oceanic c.3,000–3,300 BP calibration | Polynesian, Fijian varieties; Rotuman debated | Archaeology-informed estimate |
| Mandarin | Late Shang Old Chinese texts c.1250–1045 BCE | Wu, Yue, Min, Hakka, Gan, Xiang, Jin, others | Text dates artifact, not speech origin |
| Yoruba | Proto-Yoruboid proposed c.2500–300 BCE | Itsekiri, Igala, Yoruba varieties | Low-confidence interdisciplinary model |
| Hebrew | Canaanite c.1550–1200 BCE; Hebrew differentiates near Bronze/Iron transition | Phoenician, Ammonite, Moabite, Edomite | Gradual boundary |

Age refers to ancestor/stage, not unchanged modern language. Proto-languages are reconstructed. Dates based on inscriptions, archaeology and comparative inference are not interchangeable.

| Language | Syllables / sentence profile | Script / encoding |
|---|---|---|
| Spanish | (C)(C)V(C), often SVO, flexible order | Latin; ñ, acute accents, ü |
| Fijian | open CV/V, often VOS | Missionary-era Latin spelling; b/d/q prenasalized values |
| Mandarin | (C)(G)V(X), tones, SVO/topic-comment | Han characters; auxiliary Pinyin |
| Yoruba | canonical V/CV, tone, SVO | Latin underdots and tone marks |
| Hebrew | modern (C)(C)V(C), Biblical verb-initial tendency / Modern SVO | Paleo-Hebrew then square script; optional niqqud |

Unicode represents abstract characters and combining marks, not handwriting strokes, order, pressure, or all glyph variants. These five standard orthographies have no native subscript letters; scholarly subscript notation is analytical. Preserve diacritics in canonical text. Sound changes are scoped examples, not universal transformations. Siblinghood does not imply mutual intelligibility.
