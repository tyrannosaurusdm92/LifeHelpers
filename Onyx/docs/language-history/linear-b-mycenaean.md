# Mycenaean Greek (Linear B)

**Family:** Indo-European / Hellenic. **Root and evidence:** Proto-Greek ancestry; Mycenaean Greek is directly recorded in Linear B, which is the script, not the language.

Detailed lineage, chronology, sound-change, syllable/syntax, and script/Unicode chapters are collected in the [extended atlas](research/extended/linear-b-mycenaean/README.md). The age assessment distinguishes reconstructed roots from first attestations and records confidence and source keys.
