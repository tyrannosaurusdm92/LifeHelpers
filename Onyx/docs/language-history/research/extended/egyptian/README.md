# Ancient Egyptian (historical stages; Afroasiatic)

This folder contains five research notes and paired JavaScript modules for lineage, chronology, sound change, syllable/syntax, and script/Unicode. The research distinguishes direct evidence from reconstruction and treats dating ranges as model-dependent.

| Note | Focus |
|---|---|
| [Lineage](01-lineage.md) | Family placement and comparison branches |
| [Chronology](02-chronology.md) | Attestations versus reconstructions |
| [Sound](03-sound-change.md) | Sound systems and change |
| [Syntax](04-syllables-and-syntax.md) | Syllable structure and syntax |
| [Script](05-script-and-unicode.md) | Writing systems, Unicode, marks and glyphs |

See the parallel executable record at `Onyx/js/language-history/research/egyptian/`.
