# Yoruba (standard orthography; dialect continuum) research files

This language has five topic notes: lineage, chronology, sound change, syllable/syntax, and script/Unicode. Its six JavaScript files preserve structured evidence, source links, scope caveats, and a compatibility profile. Start with [lineage](01-lineage.md), then use the [script and Unicode note](05-script-and-unicode.md) when handling text.

Root-date caution: The roughly 12,000 BP value is a broad family-expansion estimate, not a securely reconstructed point date for Proto-Niger-Congo. Only the early part of the Proto-Yoruboid window exceeds 2,500 years. These distinct claims should not be collapsed into a precise date for Yoruba.
