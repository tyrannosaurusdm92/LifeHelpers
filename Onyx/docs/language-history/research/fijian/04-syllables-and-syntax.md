# Fijian (standard, Bauan-influenced): Syllable structure, prosody and sentence patterns

**Selection:** Oceanic language.  
**Lineage:** Austronesian → Malayo-Polynesian → Oceanic → Central Pacific → Fijian varieties → Standard Fijian.

Fijian syllables are open, with a practical broad shape V or CV; primary stress falls on the penultimate mora, which can place it on the final syllable when that syllable contains a long vowel or diphthong. Secondary stress may occur in longer words, and suffixation can shift stress. The standard language has five vowel phonemes. Orthographic letter sequences can represent a single phoneme or a phonological sequence, so character count is not syllable count: b, d and q each have a single-letter spelling for prenasalized sounds, while dr uses two letters for a special consonant value. Analyses of vowel length versus vowel sequences are a known orthographic and phonological issue; scholarly macrons or doubled vowels should be retained only when the cited source’s transcription system calls for them.

Basic transitive clauses are often described as verb–object–subject (VOS), with the object and subject following the verb phrase; constituent order can shift with discourse and clause structure. Fijian grammar also uses verbal and nominal classification, transitivity marking and complex argument expression. A single English-like SVO template would therefore misrepresent the language. The profile gives a broad VOS tendency and records the evidence source; it does not claim every clause has that order or derive syntax from word order alone.

## Compact structural record

| Feature | Summary |
|---|---|
| Syllable profile | Open V/CV syllables; five vowels; primary stress targets the penultimate mora (often penultimate syllable, but final if heavy); consonant letter sequences do not map one-to-one to phoneme count. |
| Sentence pattern | Transitive clauses are often VOS/verb-initial; argument marking and discourse permit other orders. |
