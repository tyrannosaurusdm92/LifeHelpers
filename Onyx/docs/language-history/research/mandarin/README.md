# Mandarin Chinese (Standard Mandarin focus) research files

This language has five topic notes: lineage, chronology, sound change, syllable/syntax, and script/Unicode. Its six JavaScript files preserve structured evidence, source links, scope caveats, and a compatibility profile. Start with [lineage](01-lineage.md), then use the [script and Unicode note](05-script-and-unicode.md) when handling text.

Root-date caution: The models support an ancestor older than 2,500–3,500 years, but they do not date Mandarin or the Sinitic branch directly. Sino-Tibetan internal classification and the Sinitic/non-Sinitic branching model remain debated. Oracle-bone writing dates an artifact record, not spoken language origin.
