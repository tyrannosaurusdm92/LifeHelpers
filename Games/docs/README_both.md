# LifeHelpers Offline HTML Games — Desktop + Mobile

A curated collection of offline, single-file HTML games selected for use across **desktop and mobile** environments. These games are intended to be reusable by LifeHelpers and other projects that share the same repository resources.

## Usage

Each game is stored as a standalone `.html` file. Open a game file directly in a modern browser, or serve it from the repository as part of a website/app. Because the games inline most or all of their resources, individual HTML files may be large.

> **Compatibility note:** This `both` collection was selected for desktop + mobile/touch use. Exact behavior can still vary by browser, device, screen size, and whether a particular game also exposes keyboard controls.
