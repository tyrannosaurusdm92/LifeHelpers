    Primitives

    Objects are generated as editable Three.js meshes. Use Sculpt for vertex-level shaping and the inspector for exact transforms.

    Geometry Operations

    Sculpt Brush

    Paint directly on the selected mesh. Imported low-poly meshes may benefit from Tessellate first.

    Surface Texture

    Direct paint uses the mesh UV coordinates. Swatches below replace the texture canvas and can then be painted over.

    Material Swatches

    Parametric Avatar Blockout

    This is a project-neutral 3D starting body. other projects can map its own identities, presets, clothing, prosthetics, and mobility systems onto the exported mesh or sprite sheet.

    2D / 2.5D Representation

    The 8-direction sheet is designed as a 3D→2D/2.5D handoff: one authored 3D model can provide directional sprites while remaining editable in this studio.

    Savanski 3D Editor

    Create primitives, import models, transform objects, sculpt mesh vertices, paint UV textures, generate a parametric avatar blockout, and export GLB/OBJ/STL/PLY or 2D/2.5D sprite sheets.

    Shortcuts

    W move · E rotate · R scale · F frame · Delete delete · Ctrl/Cmd+Z undo · Ctrl/Cmd+Shift+Z redo.

    Recommended avatar workflow

    Create Avatar → adjust proportions → sculpt facial/body regions → paint materials → export GLB for future edits → export 8-direction sheet for 2D/2.5D runtime use.

    For best reliability, open studio.html through a local/static web server. Core editing is local-first and does not require the Apps Script backend. This workspace runs locally inside the Savanski OurSpace game package. The editor includes a JavaScript fallback if WASM is unavailable.
