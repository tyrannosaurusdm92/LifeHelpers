SAVANSKI ART STUDIO — COMPLETE TOOL & COLOR PALETTE INVENTORY
========================================================================

Hosting target: https://github.com/tyrannosaurusdm92/LifeHelpers/tree/main/Games
Hosting model: public static GitHub content; no account is required to launch Savanski.
OurSpace integration: optional host/session bridge and backend backup; local editing/saving remains available without account authentication.
Terminology: the studio uses CANVAS / CANVAS SET language. Legacy publication-format terminology has been removed from first-party studio code and documentation; canvas terminology is used throughout.
Architecture: one HTML entrypoint only (`studio.html`) with exactly two workspace tabs: Studio and 3D Editor.
Desktop target: 1915 × 58 px title strip + 1915 × 80 px active toolbar + 1915 × 647 px active editing workspace.

SECTION 1 — CORE 2D STUDIO TOOLS
------------------------------------------------------------------------

[SELECTION]
- Rectangular Select (select): Drag a rectangular selection.
- Free-form Select (free-select): Free-form selection shell; uses selection overlay.
- Select All (select-all): Select the full canvas.
- Deselect (deselect): Clear the active selection.

[IMAGE]
- Crop Layer (crop): Crop the active layer non-destructively to the chosen canvas region.
- Local Background Remover (background-remove-local): Remove a mostly solid background by sampling corner colors.

[TRANSFORM]
- Move / Position (move): Move the active layer.
- Rotate Left 90° (rotate-left): Rotate active layer left.
- Rotate Right 90° (rotate-right): Rotate active layer right.
- Flip Horizontal (flip-horizontal): Mirror active layer horizontally.
- Flip Vertical (flip-vertical): Mirror active layer vertically.
- Center Layer (center-layer): Center the active layer.
- Scale / Resize Layer (scale-layer): Resize the active layer independently on X and Y while keeping the print canvas fixed.
- Fit Layer to Canvas (fit-layer): Fit all visible pixels of the active layer within the fixed canvas bounds.
- Fill Canvas with Layer (fill-layer): Scale the active layer to cover the fixed canvas bounds edge to edge.

[DRAW]
- Brush (brush): General round brush.
- Pencil (pencil): Hard-edge pencil.
- Marker (marker): Semi-transparent marker.
- Airbrush (airbrush): Soft spray brush.
- Calligraphy (calligraphy): Flat calligraphy brush.
- Crayon (crayon): Textured crayon-style brush.
- Watercolor (watercolor): Layerable transparent watercolor brush.
- Eraser (eraser): Erase to true transparency.
- Paint Bucket (fill): Flood fill an enclosed color area.

[COLOR]
- Eyedropper (eyedropper): Sample a color from the canvas.

[RETOUCH]
- Blur Brush (blur-brush): Locally soften details.
- Sharpen Brush (sharpen-brush): Locally sharpen edges.
- Dodge (dodge): Locally lighten areas.
- Burn (burn): Locally darken areas.
- Clone Stamp (clone-stamp): Clone pixels from a sampled source.
- Smudge (smudge): Blend nearby pixels.

[SHAPES]
- Line (line): Draw a line with current fill and stroke.
- Rectangle (rectangle): Draw a rectangle with current fill and stroke.
- Rounded Rectangle (roundrect): Draw a rounded rectangle with current fill and stroke.
- Ellipse (ellipse): Draw a ellipse with current fill and stroke.
- Triangle (triangle): Draw a triangle with current fill and stroke.
- Star (star): Draw a star with current fill and stroke.
- Arrow (arrow): Draw a arrow with current fill and stroke.
- Heart (heart): Draw a heart with current fill and stroke.
- Speech Bubble (speech): Draw a speech bubble with current fill and stroke.

[TEXT]
- Add / Edit Text (text): Insert an editable text layer.
- Typography Inspector (text-inspector): Open the complete text inspector.
- Load Custom Font (custom-font): Load a font from the user device without bundling it.
- Style Selected Letters (text-segment-style): Apply color, opacity, or highlight to selected characters.
- Text Stroke / Outline (text-stroke): Configure text outline color and width.
- Text Highlight (text-highlight): Highlight full or partial text.
- Letter & Line Spacing (text-spacing): Control tracking and line height.
- Bend Text on Curve (text-bend): Curve text along an arc.
- Text Shadow (text-shadow): Configure shadow color, blur, and offset.
- Text Gradient (text-gradient): Create a two-color angle-controlled text gradient.
- Text Texture (text-texture): Use a user-selected image as a text texture source.
- 3D Text Depth (text-3d): Simulate depth and dimensional extrusion.
- Text Perspective / 3D Rotation (text-perspective): Skew and rotate text in perspective.
- Text Behind Image (text-behind): Use layer order and erasing/background removal to place type behind a subject.

[ADJUSTMENTS]
- Auto Enhance (auto-enhance): Improve color, lighting, and contrast.
- Brightness (brightness): Lighten or darken the active layer.
- Contrast (contrast): Increase or reduce tonal contrast.
- Saturation (saturation): Adjust color intensity.
- Hue Rotate (hue): Rotate hues.
- Black & White (grayscale): Convert to grayscale.
- Sepia (sepia): Apply sepia toning.
- Invert (invert): Invert image colors.
- Gaussian Blur (blur): Blur the layer.
- Sharpen (sharpen): Sharpen detail.
- Unblur / Detail (unblur): Apply local high-pass-style sharpening.
- Clarity (clarity): Increase local edge clarity.
- Dehaze (dehaze): Increase contrast and atmospheric clarity.
- Auto Levels (auto-levels): Stretch tonal range.
- Vignette (vignette): Darken the outer edges.
- Grain (grain): Add film-like grain.
- Pixelate (pixelate): Create a pixel-art mosaic effect.
- Duotone (duotone): Map luminance between two colors.
- Vintage Filter (vintage): Apply a warm faded vintage look.
- Cool Filter (cool): Apply a cooler color treatment.
- Warm Filter (warm): Apply a warmer color treatment.
- Noir Filter (noir): High-contrast monochrome filter.
- Fade Filter (fade): Lower contrast and saturation.

[LAYERS]
- New Layer (add-layer): Create a transparent paint layer.
- Duplicate Layer (duplicate-layer): Duplicate active layer.
- Delete Layer (delete-layer): Delete active layer.
- Move Layer Up (layer-up): Move active layer forward.
- Move Layer Down (layer-down): Move active layer backward.
- Merge Down (merge-down): Merge active layer into the one below.
- Add Layer Mask (layer-mask): Add a white editable layer mask.
- Remove Layer Mask (remove-mask): Remove the active mask.
- Blend Modes (blend-mode): Choose a canvas blend/compositing mode.
- Layer Opacity (opacity): Set layer transparency.

[LAYOUT]
- Positioning Grid / Snap (snap-grid): Toggle non-exporting alignment guides and snapping.
- Pin Background (pin-background): Lock the Cover Base layer.
- Collage Layout (collage): Arrange visible art layers into a balanced grid.
- Bleed & Safe Guides (guides): Toggle non-exporting bleed/safe-area guides.
- Canvas Layout Preset (canvas-layout): Create editable title, subtitle, and supporting text layers.

[ELEMENTS]
- Emoji / Sticker (emoji-sticker): Insert an emoji as an editable text element.
- Shape Library (shape-library): Open the internal vector shape set; no image assets required.
- Image Overlay (overlay-image): Import an image as a new editable layer.

[CANVAS SET]
- Add Canvas (canvas-add): Add a canvas at the selected canvas size.
- Duplicate Canvas (canvas-duplicate): Duplicate the current canvas.
- Delete Canvas (canvas-delete): Delete the current canvas.
- Previous Canvas (canvas-prev): Go to the previous canvas.
- Next Canvas (canvas-next): Go to the next canvas.
- Export Canvas Set (export-canvases): Export all canvases as individual PNGs.

[FILE]
- Save Project (save): Save editable project to IndexedDB.
- Export .lfstudio Project (export-project): Download an editable project JSON.
- Export PNG (export-png): Export print-resolution PNG with transparency.
- Export JPG (export-jpg): Export print-resolution JPEG on white.
- Export WebP (export-webp): Export WebP.
