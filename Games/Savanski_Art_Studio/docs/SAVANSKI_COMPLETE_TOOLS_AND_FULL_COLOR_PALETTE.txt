SAVANSKI ART STUDIO — COMPLETE STUDIO + 3D EDITOR TOOL & COLOR PALETTE REFERENCE
========================================================================================

Build architecture: one studio.html containing Home / Projects, Studio, and 3D Editor.
Project library: Studio and 3D Editor projects share one local Savanski project library.
Hosting: public static GitHub-compatible build; an account is not required to launch or edit locally.
OurSpace: optional session-aware backup is used when Savanski is embedded in an authenticated OurSpace host.

APP HOME / PROJECT LIBRARY
----------------------------------------------------------------------------------------
- Home / Projects — open the shared project library from either Studio or 3D Editor.
- Studio tab — configure and create a new Studio canvas project.
- 3D Editor tab — create a new 3D scene or import supported 3D project/model files.
- Open / Edit — open a saved project in the editor that created it.
- Rename — rename a saved project without changing its project identity.
- Duplicate — make an independent copy with a new project ID so original and copy can be edited separately.
- Delete — remove a project from the local Savanski project library.
- Back to Editor — close Home and return to the currently active project.
- Studio Save — update the current Studio project in the shared library.
- 3D Save — update the current 3D project in the shared library.
- OurSpace backup — when a valid OurSpace session exists, project saves can also be backed up through the host bridge.
