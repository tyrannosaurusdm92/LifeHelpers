Onyx game sprite images extracted from the embedded CAT-astrophic Cuteness archive in LifeHelpers/main/OurSpace/assets/code/game.html.

The game internally refers to these entries with .png names, but the actual embedded image bytes use AVIF format. Files are exported with the correct .avif extension, without any conversion or quality loss.

onyx.avif and mosswood_characters--onyx.avif are intentionally two filenames containing the same game image, matching the embedded archive's logical paths.

SOURCE_MANIFEST.json records the exact original asset paths, archive entry IDs and Git blob hashes.

Images are unmodified. No image was drawn, recreated or edited.
